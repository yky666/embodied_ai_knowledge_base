07 · GPU 显存、训练资源与部署预算

2. 参数状态：逐项乘字节

LaTeX 源码
M_{state}\approx Pb_w+P_t(b_g+b_o+b_m).\tag{7.2}

全参训练 P_t=P。Adam 两个 FP32 moment 给 bo=8b_o=8bo​=8；如独立 FP32 master 给 bm=4b_m=4bm​=4。是否存在 master、梯度是否 FP32、状态是否低精度，取决于实现。

示例仅采用 BF16 权重 2B、BF16 梯度 2B、FP32 moments 8B、不含 master：

3. 激活、注意力与 KV cache

推导 2 · 为什么图像分辨率影响大，以及 KV 数量

常规 Transformer 激活包含若干 B×N×dB\times N\times dB×N×d 张量，显式 attention 权重还有 B×h×N×NB\times h\times N\times NB×h×N×N：

Mact∼O(LBNd)+O(LBhN2).(7.4)M_{act}\sim O(LBNd)+O(LBhN^2).\tag{7.4}Mact​∼O(LBNd)+O(LBhN2).(7.4)
LaTeX 源码
M_{act}\sim O(LBNd)+O(LBhN^2).\tag{7.4}

这描述张量规模，常数、层间寿命和 fused 算子会改变峰值。图像长宽同时翻倍，ViT token 数近似增四倍，显式注意力元素增十六倍。FlashAttention 避免把完整权重矩阵写入显存，但不使一般全注意力计算量从二次自动变为线性。

增量推理每层缓存 K 与 V：

MKV=2LBNhkvdhbkv.(7.5)M_{KV}=2LBNh_{kv}d_hb_{kv}.\tag{7.5}MKV​=2LBNhkv​dh​bkv​.(7.5)
LaTeX 源码
M_{KV}=2LBNh_{kv}d_hb_{kv}.\tag{7.5}

取 L=32、B=1、N=4096、h_kv=8、d_h=128、BF16 2B，得 536870912 bytes=0.5 GiB；改为 32 个 KV heads 时为 2 GiB。并发 batch 与上下文长度线性放大缓存，视觉和视频 token 也计入 N。

4. LoRA、分片与累积

推导 3 · 低秩参数量与理想分片下界

线性权重 W∈Rdout×dinW\in\mathbb R^{d_{out}\times d_{in}}W∈Rdout​×din​ 的更新 ΔW=(α/r)BA\Delta W=(\alpha/r)BAΔW=(α/r)BA，B∈Rdout×r,A∈Rr×dinB\in\mathbb R^{d_{out}\times r},A\in\mathbb R^{r\times d_{in}}B∈Rdout​×r,A∈Rr×din​：

PLoRA=r(din+dout),PLoRAPW=r(din+dout)dindout.(7.6)P_{LoRA}=r(d_{in}+d_{out}),\qquad\frac{P_{LoRA}}{P_W}=\frac{r(d_{in}+d_{out})}{d_{in}d_{out}}.\tag{7.6}PLoRA​=r(din​+dout​),PW​PLoRA​​=din​dout​r(din​+dout​)​.(7.6)
LaTeX 源码
P_{LoRA}=r(d_{in}+d_{out}),\qquad\frac{P_{LoRA}}{P_W}=\frac{r(d_{in}+d_{out})}{d_{in}d_{out}}.\tag{7.6}

冻结主干省梯度 / 优化器，但权重仍存在，反传经过主干仍可能保留大量激活。量化主干和 LoRA 是两个独立选择。

理想 D 卡 ZeRO 状态存储（不含临时 all-gather、冗余和激活）：

MZ1≈Mw+Mg+Mo/D,MZ2≈Mw+(Mg+Mo)/D,MZ3≈(Mw+Mg+Mo)/D.(7.7)\begin{aligned}M_{Z1}&\approx M_w+M_g+M_o/D,\\M_{Z2}&\approx M_w+(M_g+M_o)/D,\\M_{Z3}&\approx(M_w+M_g+M_o)/D.\end{aligned}\tag{7.7}MZ1​MZ2​MZ3​​≈Mw​+Mg​+Mo​/D,≈Mw​+(Mg​+Mo​)/D,≈(Mw​+Mg​+Mo​)/D.​(7.7)
LaTeX 源码
\begin{aligned}M_{Z1}&\approx M_w+M_g+M_o/D,\\M_{Z2}&\approx M_w+(M_g+M_o)/D,\\M_{Z3}&\approx(M_w+M_g+M_o)/D.\end{aligned}\tag{7.7}

这里 M_o 含要分片的 optimizer / master 状态，具体分片配置可不同。通信 buffer、参数 materialization 和网络互联决定真实峰值及速度。

Beffective=Bmicro Ka D.(7.8)B_{effective}=B_{micro}\,K_a\,D.\tag{7.8}Beffective​=Bmicro​Ka​D.(7.8)
LaTeX 源码
B_{effective}=B_{micro}\,K_a\,D.\tag{7.8}

累积仅降低单次激活峰值，参数状态不减；损失缩放、梯度同步和最后不完整 batch 需处理。checkpointing 以重算换内存；CPU offload 以带宽和主机内存换 VRAM。

5. 实测步骤与选型维度

  1. 记录模型、可训练参数、精度、优化器、分片和 checkpoint 配置。
  2. 分别测训练 forward/backward/update 峰值与推理 prefill/decode 峰值。
  3. 同步 GPU 后统计 allocated / reserved 与耗时；记录框架、CUDA、驱动和设备。
  4. 扫描 batch、序列、分辨率和去噪步数，记录吞吐、p95 延迟与 OOM 边界。
  5. 选型比较容量、带宽、精度实际吞吐、互联、散热、电力和预算，使用目标任务 benchmark。
