如何补充知识库

基础讲义 · 2026-10-12 · 本地公式与矢量图 · 点击图示放大
CONTENTS · 本页目录

每个主题建议依次包含：问题与应用 → 符号与单位 → 假设 → 核心公式 → 逐步推导 → 算法或架构 → 数值例子 → 局限 → 原始来源。

  • 编辑对应 Markdown；行内公式用单美元定界，块公式用双美元定界。
  • 详细推导放在 details.derivation 中，默认 open；图示用 Mermaid 代码块或独立 SVG。
  • 引用原论文、教材或官方文档。说明自己的教学简化，不把研究索引当作完整方法解析。
  • 公式注明参考系、形状、单位与时间语义；同一符号在不同领域复用时重新定义。
  • 新增模块时更新首页导航、README 和构建脚本中的模块摘要。

提交前运行：

npm ci
npm run build
npm test
npm run check:browser

同时提交 Markdown、生成的 HTML、图示及必要资源。不要提交 node_modules、本地备份、运行日志、凭证或个人检查截图。浏览器检查验证离线加载、链接、图示、排版和基础交互；推导与科学结论仍需人工审阅。
