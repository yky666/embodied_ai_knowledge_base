# Embodied AI Knowledge Base

AI、机器人学与空间智能的中文基础知识库。以带注解的架构图、符号表、逐步公式推导和交互实验连接模型、三维空间与闭环行动。

**阅读 HTML：** 下载仓库并打开 [index.html](index.html)。公式、图示、字体和实验可离线使用，外部论文链接需要联网。GitHub 文件预览适合阅读 Markdown，完整排版与交互请使用 HTML 页面。

## 阅读功能

- LaTeX 在构建时通过 KaTeX 编译为 HTML + MathML，使用本地字体，保留源码与公式编号。
- 经典 Transformer 展示编码器 / 解码器、残差、归一化、因果遮罩和交叉注意力的 Q/K/V 来源。
- Mermaid 在构建时生成独立 SVG；点击图可放大，并查看图示源码。
- 默认展开详细推导，可一键切换精简模式；打印时自动展开，可通过浏览器保存为 PDF。
- 页面适配桌面与手机，运行时不依赖 CDN。

## 本地构建与检查

阅读已提交的 HTML 不需要安装依赖。编辑讲义后再构建，要求 Node.js 20 或更新版本：

```bash
git clone https://github.com/yky666/embodied_ai_knowledge_base.git
cd embodied_ai_knowledge_base
npm ci
npm run build
npm test
npm run check:browser
```

重新生成讲解视频需要 Python（edge-tts 语音合成、imageio-ffmpeg 编码）并联网，步骤见 [18 视频讲解](18_视频讲解.md) 末尾。

Puppeteer 使用安装时提供的浏览器；Windows 也会识别常见的 Edge 安装路径。可通过 `PUPPETEER_EXECUTABLE_PATH` 指定已有 Chrome / Chromium / Edge。浏览器检查验证链接、离线加载、图示、手机布局和关键交互；它不代替推导的科学审阅。

## 文件结构

|位置|用途|
|---|---|
|`*.md`|可编辑讲义和来源|
|`*.html`|可直接阅读的预编译页面|
|`assets/`|SVG、Mermaid 源、本地字体、样式和交互代码|
|`scripts/`|跨平台构建、检查与视频生成脚本|
|`video/`|视频分镜（`lessons/*.js`）与 Canvas 动画引擎|
|`videos/`|生成的 MP4、SRT 字幕与封面|
|`third-party/`|随页面分发的第三方资源许可声明|
|`.github/workflows/check.yml`|提交和 PR 的自动检查|

同时保存源码与生成页面，方便学习、修订和追踪历史。依赖、本地备份和临时检查结果不入库。
