制作方式与重新生成

视频由脚本自动生成，源文件都在仓库中：

  • video/lessons/*.js：每个视频的分镜。每个场景包含旁白文本 say 和一个 Canvas 绘制函数 draw(g, p)，p 为场景进度 0→1。
  • video/engine.js：绘图工具、标题栏、进度条与字幕渲染。
  • scripts/video.cjs：调用 edge-tts 合成中文语音并得到逐句时间轴，按语音长度安排场景时长，在无头浏览器中逐帧渲染，再用 ffmpeg 编码为 H.264 MP4，同时导出 SRT 字幕与封面，最后重新生成本页。
python -m venv .venv
.venv/Scripts/pip install edge-tts imageio-ffmpeg   # macOS / Linux 使用 .venv/bin/pip
npm run video                 # 生成全部视频
npm run video -- v05          # 只生成编号前缀为 v05 的视频
npm run video -- --stills     # 只导出每个场景的预览帧到 build/stills
npm run build

语音合成需要联网访问 edge-tts 服务；可用环境变量 VIDEO_VOICE（如 zh-CN-XiaoxiaoNeural）与 VIDEO_RATE（如 +10%）调整音色和语速，FFMPEG_PATH、EDGE_TTS 指定可执行文件。修改旁白后重新运行即可，未改动的语音会使用 build/tts 缓存。

动画是教学示意：数值多为演示用的简化参数，严格的定义、假设与推导以对应讲义为准。
